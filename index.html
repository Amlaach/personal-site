Core Systems Flagship

HDDE

Zero-allocation decision engine for high-performance systems.

0 Allocations Rust ECS / SoA
Why I built it
To cut out heap memory allocation completely during dynamic decision evaluation.
What makes it interesting
Puts dynamic decision trees into flat memory buffers. Keeps data right next to CPU cache and avoids memory allocations while running.

Otzaria Semantic Search

Fast search combining exact text and meaning for Hebrew books.

594K Lexical Links Hebrew Semantic Search Qwen3 Embedding 0.6B
