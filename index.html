Core Systems Flagship

HDDE

Zero-allocation hierarchical decision architecture for high-performance systems.

0 Allocations Rust ECS / SoA
Why I built it
To eliminate runtime heap allocation overhead in dynamic utility evaluation systems.
What makes it interesting
Organizes complex hierarchical decision trees into flat contiguous memory buffers. Maximizes CPU cache locality while avoiding dynamic allocations during execution.

Hybrid lexical + semantic retrieval for large Hebrew corpora.

594K Lexical Links Hebrew Semantic Search Qwen3 Embedding 0.6B
